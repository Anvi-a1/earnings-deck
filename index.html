Code: Quick KPI Utility (Python)

from math import pow

def cagr(start, end, years):
    """Compound Annual Growth Rate"""
    return pow(end / start, 1/years) - 1

assets_2022 = 1.85e12
assets_2025 = 2.45e12
print(f"CAGR: {cagr(assets_2022, assets_2025, 3):.2%}")

Financial Math

Net Present Value:

\[ \mathrm{NPV} = \sum_{t=1}^{T} \frac{CF_t}{(1 + r)^t} - C_0 \]

CAPM (Cost of Equity):

\[ \mathrm{E}(R_i) = R_f + \beta_i\big(\mathrm{E}(R_m) - R_f\big) \]

Remind the audience that NPV supports project selection; CAPM informs hurdle rates.
